# RIVER 포커 라운지
React + Vite + JavaScript + Three.js + Socket.IO 온라인 텍사스 홀덤 초안.

## 실행
```sh
npm install
npm run dev
```
브라우저: http://localhost:5173 . 같은 네트워크의 다른 기기는 `http://호스트의LAN_IP:5173`으로 접속합니다. Vite와 게임 서버 모두 `0.0.0.0`에 바인딩됩니다. 방화벽에서 5173 포트 접근을 허용해야 합니다. Vite가 출력한 Network 주소를 사용하세요.

테이블 입장 → 카드 받고 시작하기. 혼자이면 CPU가 참여합니다. 친구는 '친구와 플레이'에서 같은 6자리 방 코드로 입장합니다. 최대 5명이며 핸드 진행 중에는 새 참여를 받지 않습니다. 시작 자금 1억 가상 칩, 블라인드 50만/100만, 최소 레이즈 증액은 최초 100만이며 이후 직전 레이즈 증액을 따릅니다. 레이즈 단위는 50만입니다. 큰 금액 증가 버튼으로 100만/500만/1,000만을 더하거나 최대 금액을 선택할 수 있습니다. 올인은 금액 단위와 관계없이 남은 칩 전부를 베팅합니다. 짧은 잔액으로 콜하면 올인과 사이드 팟이 적용됩니다.

## 확인 및 빌드
```sh
npm test
# dev 서버가 켜져 있을 때: npm run test:socket
npm run build
npm start
```
빌드 후 `npm start`로 http://localhost:3001 에서 프론트엔드와 소켓 서버를 함께 제공합니다.

## 초안 범위
실제 금전 거래가 없는 가상 칩 게임입니다. 데이터는 서버 메모리에만 있어 재시작 시 초기화됩니다. 폴드나 도중 퇴장은 해당 플레이어만 이번 핸드에서 제외하고 남은 인원으로 계속 진행합니다. 이미 베팅한 칩은 팟에 남습니다. 잔액이 0인 플레이어는 다음 핸드부터 관전하며 다른 사람은 계속 플레이할 수 있습니다. 자동 재연결 후 새로 입장하세요. 로그인, 영구 잔액, 재접속 복구, 액션 제한시간, 정교한 CPU 전략은 포함하지 않았습니다. 닉네임을 비우면 서버에서 랜덤 이름과 동물 아바타를 지정합니다. 승리 결과에는 승자별 족보, 최선의 카드 5장, 지급액을 표시합니다. 모두 폴드한 승리는 공개된 카드까지만 표시합니다. 카드와 칩은 CSS 원근 변환 애니메이션, 테이블은 Three.js로 표시하며 동작 줄이기 설정을 존중합니다. CPU는 체크/콜 중심으로 플레이합니다. 외부 공개 전에는 인증과 요청 제한, 재접속 정책 등을 보강해야 합니다.
